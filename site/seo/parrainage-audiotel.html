FONCTIONNEMENT

Un parcours automatisé et traçable.

Le parrain n’a pas besoin de transmettre manuellement un numéro de dossier. Le lien contient le code nécessaire au rattachement de la demande.

1. Créez votre lien

Lorsque votre compte est éligible et que le programme est activé, un bouton dans votre espace client génère votre code personnel et votre lien de parrainage.

2. Partagez-le

Vous copiez le lien et le transmettez à la personne que vous souhaitez parrainer. Le lien ouvre directement le parcours de demande avec le code associé.

3. Le filleul devient client

Le simple dépôt d’une demande ne déclenche aucune récompense. Le filleul doit être réellement activé avec un abonnement actif et payé.

4. La récompense est comptabilisée

Une fois les conditions remplies, le parrainage est qualifié et la récompense prévue est enregistrée dans le suivi du parrain.

CONDITIONS DE QUALIFICATION

Le système évite les primes déclenchées trop tôt ou les doublons.

Le programme est conçu pour rémunérer une acquisition réelle, pas une simple saisie de formulaire.

Parrain éligible

Le compte du parrain doit être actif et son abonnement doit être confirmé comme payé pour créer et utiliser un code.

Pas d’auto-parrainage

Un client ne peut pas se parrainer lui-même.

Un rattachement par filleul

Une même ouverture ne peut pas être revendiquée plusieurs fois par différents codes.

Récompense après qualification

Le montant applicable est celui prévu par le programme et affiché dans l’espace client. Il est enregistré seulement après activation réelle et paiement de l’abonnement du filleul.

QUESTIONS FRÉQUENTES

Ce qu’il faut savoir avant de partager votre lien.

Une simple demande de mon filleul déclenche-t-elle la récompense ?

Non. La récompense n’est acquise que lorsque le filleul devient réellement client avec un abonnement actif et payé.

Puis-je parrainer quelqu’un avant d’avoir payé mon propre abonnement ?

Le code est réservé aux parrains dont le compte est actif et dont l’abonnement a été confirmé comme payé.

Le montant de la récompense est-il fixe ?

Le montant est configurable. La référence à utiliser est celle affichée dans votre espace client lorsque le programme est actif.

Le programme est-il toujours disponible ?

Il peut être activé ou désactivé. Si le programme n’est pas actif, le module n’est pas proposé dans l’espace client et aucun nouveau parrainage ne peut être créé.

DÉJÀ CLIENT ?

Votre espace client est le point de départ du parrainage.

Lorsque le programme est actif et que votre compte est éligible, vous pouvez y créer puis copier votre lien personnel.
