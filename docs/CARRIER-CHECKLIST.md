# Checklist opérateur SVA

À remplir avant toute mise en production réelle.

## Numéro

- 089 exact ;
- palier D080 ;
- affectation stable ;
- portabilité sortante ;
- procédure et délai de portage ;
- conservation du palier lors du portage.

## Reversement

- taux HT/min ;
- paliers de volume ;
- origine mobile/fixe ;
- éventuelle déduction mobile ;
- durée minimale ;
- incrément de facturation ;
- règle d'arrondi ;
- appels exclus ;
- impayés/fraude/chargebacks ;
- abonnement ;
- mise en service ;
- engagement ;
- délai de règlement.

## SIP

- livraison SIP directe autorisée ;
- IP/SBC primaire ;
- IP/SBC secondaire ;
- transport ;
- port ;
- codecs ;
- DTMF ;
- format CLI ;
- format DNIS ;
- P-Asserted-Identity ;
- Session-Expires ;
- limites de concurrence ;
- plage RTP ;
- TLS/SRTP si disponible.

## CDR

- format ;
- fréquence ;
- identifiant unique ;
- API ou SFTP ;
- horodatage/timezone ;
- définition de la durée reversée ;
- corrections rétroactives ;
- export de règlement.

## Exploitation

- NOC/support ;
- procédure P1 ;
- SLA si applicable ;
- maintenance planifiée ;
- délai de portage ;
- processus de contestation financière.
